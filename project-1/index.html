What Is Semantic HTML?

HTML stands for HyperText Markup Language. HTML gives a webpage structure and meaning. CSS is used to control the appearance of a webpage.

Why Semantics Matter

Semantic HTML makes webpages easier for people and assistive technologies to understand.

  1. Use meaningful headings.
  2. Organize related information.
  3. Add alternative text to images.

HTML Terms

Element
A part of an HTML document.
Attribute
Extra information added to an HTML element.
Semantic HTML
HTML that describes the meaning of content.

Example of Code

An HTML class can be written as class="example".
